# Changelog

## 0.2.0

- Add reversed() for descending iteration
- Add statistical methods: median(), percentile(), sum()
- Add closest() for nearest-value binary search lookup
- Add unique() for duplicate removal while maintaining sort order

## 0.1.2

- Standardize README to 3-badge format with emoji Support section
- Update CI actions to v5 for Node.js 24 compatibility
- Add GitHub issue templates, dependabot config, and PR template

## 0.1.1

- Standardize package metadata, badges, and CHANGELOG

## 0.1.0

- `sortedArray()` factory with binary search insert and lookup
- `insert()`, `remove()`, `has()`, `indexOf()` operations
- `range()` queries for retrieving subsets
- Custom comparator support
- Iterable interface with `Symbol.iterator`
- `length`, `first`, and `last` getters
- `toArray()` for safe copy
